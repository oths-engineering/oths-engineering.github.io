# Project guidance

## Site

- This is a static HTML/CSS/JavaScript site for the Tompkins Engineering Design Club.
- Keep the visual direction blueprint-inspired: navy/blue foundations, orange accents, technical mono labels, and generous grid-based layouts.
- The club motto is "Plan, Prototype, Perfect."
- Preserve accessible semantic HTML, responsive layouts, descriptive image alt text, and working external links.
- Use the existing logo and blueprint artwork from `.archive/assets/` unless new assets are intentionally added.

## Validation

- This project has no package manager or test suite. Validate changes by inspecting the rendered static files and checking links/paths.
